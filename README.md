# Paradise Nursery — Shopping Application

A front-end shopping application for **Paradise Nursery**, a fictional houseplant
retailer. Browse eighteen houseplants across three categories, add them to a cart,
adjust quantities, and review the running total.

Built with **React**, **Redux Toolkit**, and **Vite**.

---

## Features

### Landing page
- Full-bleed background image
- Company name and tagline
- Paragraph about the company (`AboutUs.jsx`)
- **Get Started** button that opens the product listing page

### Product listing page
- 18 unique houseplants grouped into 3 categories
  (Air Purifying, Low Maintenance, Statement Plants)
- Each plant shows a thumbnail, name, description, and price
- **Add to Cart** button that disables itself once the plant is in the cart
- Adding a plant increments the cart badge in the header

### Header (product listing + cart pages)
- Shopping cart icon with a badge showing the live total number of items
- Navigation to all three pages: **Home**, **Plants**, **Cart**

### Shopping cart page
- Total number of plants in the cart
- Total cost of all items
- Every plant shows its thumbnail, name, and unit price
- Per-plant line total (unit price × quantity)
- **+** and **−** buttons that update the line total, the cart total, and the
  header badge; decrementing past 1 removes the plant
- **Delete** button for each plant
- **Checkout** button showing a "Coming Soon" message
- **Continue Shopping** button that returns to the product listing page

## Redux state

The cart lives in a single slice (`src/CartSlice.jsx`) created with
`createSlice`, registered on the store with `configureStore`.

**State shape**

```js
{
  cart: {
    items: [
      { name, image, cost, description, quantity }
    ]
  }
}
```

`cost` is stored as a **number**, so totals never depend on parsing a `"$12.00"`
string back into a value.

**Actions**

| Action | Payload | Effect |
| --- | --- | --- |
| `addItem` | plant object | Adds the plant, or increments its quantity if already in the cart |
| `removeItem` | plant name | Removes the plant from the cart entirely |
| `updateQuantity` | `{ name, quantity }` | Sets an exact quantity; zero removes the plant |
| `clearCart` | — | Empties the cart |

**Selectors**

| Selector | Returns |
| --- | --- |
| `selectCartItems` | The array of cart line items |
| `selectTotalQuantity` | Total number of plants, counting quantities |
| `selectTotalAmount` | Total cost of everything in the cart |

Because the **Add to Cart** disabled state is derived from `selectCartItems`
rather than tracked in local component state, deleting a plant from the cart
automatically re-enables its button on the product listing page.

## Running locally

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

Other scripts:

```bash
npm run build     # production build into dist/
npm run preview   # serve the production build locally
npm run images    # regenerate the plant artwork
```

## Deploying to GitHub Pages

`vite.config.js` uses `base: './'`, so the build works under any repository
name without further configuration.

**Option A — the `gh-pages` package**

```bash
npm run deploy
```

Then in the repository: **Settings → Pages → Build and deployment → Deploy from
a branch**, and select the `gh-pages` branch with the `/ (root)` folder.

**Option B — GitHub Actions**

The workflow in `.github/workflows/deploy.yml` builds and publishes on every
push to `main`. Enable it under **Settings → Pages → Build and deployment →
Source → GitHub Actions**.

## Notes on the artwork

The plant thumbnails and the landing-page background are SVGs generated by
`scripts/generate-images.mjs` rather than linked stock photos. That keeps the
repository self-contained, so the deployed site can never show a broken image
or depend on a third-party host staying online. Run `npm run images` to
regenerate them.
